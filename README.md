# ⚔️ Relic Clash — Medieval Rock, Paper, Scissors

Step forth, brave soul, and declare thy weapon! **Relic Clash** is an interactive, dark-fantasy web game that transforms classic Rock-Paper-Scissors into a battle of ancient artifacts. Test thy fate against the automated Foe in a fully responsive medieval arena.

---

## 🏰 Features

* **Authentic Medieval Aesthetics:** Styled with Cinzel typography, rich royal gradients, and glowing elemental card hovers.
* **Ancient Relics:** 
  * 🪨 **Stone** *(Rock)*
  * 📜 **Parchment** *(Paper)*
  * ⚔️ **Twin Blades** *(Scissors)*
* **Dynamic Battle Logic:** Clean JavaScript state management handling custom victory, defeat, and draw conditions with tailored medieval phrasing.
* **Responsive Layout:** Optimized using CSS Flexbox and media queries to look sharp on desktop monitors, tablets, and mobile screens alike.

---

## 🛠️ Built With

* **HTML5** — Semantic page structure
* **CSS3** — Custom layout, gradients, box shadows, and responsive media queries
* **JavaScript (ES6+)** — Game logic, randomized AI choices, and dynamic DOM manipulation
